# Samples

This directory holds **mock** input/output examples for demos, tests, and documentation.

## Rules

- Only synthetic or anonymized mock content is allowed.
- Do **not** commit real company documents, intranet exports, internal screenshots, secrets, logs, or personal data.
- Uploaded knowledge corpora for running systems belong in Docker volumes / local data paths ignored by Git, not here.

## Layout

| Path | Purpose |
|---|---|
| `input/` | Mock source documents or fixtures |
| `output/` | Mock transformation / retrieval artifacts |
